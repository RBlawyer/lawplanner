# lawplanner
KU Leuven Law University planner
Dit is een planning voor rechtenstudenten die ingeschreven zijn op KU Leuven. Gelieve deze website alleen voor studie doeleinden te gebruiken, het is gemaakt door en voor studenten.
Deze website is simpel gemaakt voor examens, een planning waar je gemakkelijk aan kan.
Je moet eerst een username aanmaken en daarna een wachtwoord.
VERGEET JE WACHTWOORD NIET! één keer vergeten, kan je niet meer aan je account geraken, dus schrijf je wachtwoord ergens op.
Eens aangemeld, kan je de functies van de website gebruiken, zoals je studies plannen en een timer opzetten en alleen dat open laten staan, zodat je gefocust bent.
Veel success, ik hoop van harte dat dit nuttig is voor jullie!
